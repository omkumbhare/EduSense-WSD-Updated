Core Scoring Formulation

Given an educational transcript sentence $T$ containing an ambiguous target word $w$, the engine extracts a surrounding context window $C$. For every candidate WordNet synset $s \in \text{Synsets}(w)$, the system calculates a multi-factor transparent overlap score:

Final Score(s) = α · DirectOverlap(C, Gs) + β · LemmaOverlap(Clemma, Gs,lemma) + γ · ExampleOverlap(Clemma, Es,lemma) + δ · ThesaurusOverlap(Scontext, Gs,lemma) + ε · HypernymOverlap(Clemma, Hs)
Variable Definitions & Default Parameters:
Parameter Weight Description
α (alpha) 1.5 Exact direct token overlap between filtered transcript context $C$ and WordNet gloss definition tokens $G_s$.
β (beta) 1.2 Lemma-level overlap between context lemmas $C_{\text{lemma}}$ and candidate gloss lemmas $G_{s,\text{lemma}}$.
γ (gamma) 1.0 Example sentence lemma overlap between context lemmas $C_{\text{lemma}}$ and WordNet example sentence lemmas $E_{s,\text{lemma}}$.
δ (delta) 0.7 Thesaurus synonym expansion overlap between context synonyms $S_{\text{context}}$ and candidate gloss lemmas.
ε (epsilon) 0.5 Hypernym & hyponym hierarchy token overlap matching general academic domains.
Relative Confidence Calculation:

Relative confidence measures how strongly the predicted sense dominates alternative senses:

Relative Confidence = Top Score / ∑ (All Candidate Scores)

Evaluator Viva Examination Questions & Answers

WSD is an open problem in Natural Language Processing (NLP) that aims to identify which sense of a polysemous word (a word with multiple meanings, e.g. 'bank' as river bank vs financial bank) is used in a given sentence context.

Standard Lesk counts exact raw word overlaps between context and candidate definitions. Our engine enhances this by adding: 1) Lemma-level matching, 2) Example sentence matching, 3) Thesaurus synonym expansion for context words, 4) Hypernym hierarchy matching, and 5) Target self-match exclusion to prevent bias.

The objective of an academic mini-project is to demonstrate core NLP principles, algorithms, and transparent explainable decision logic. LLM APIs act as black boxes. By using WordNet and explicit gloss overlap scoring, every step of the computation is reproducible, mathematical, and inspectable.

WordNet is a large lexical database of English developed at Princeton University. Nouns, verbs, adjectives, and adverbs are grouped into sets of cognitive synonyms called synsets, each expressing a distinct concept with definitions, examples, and semantic relations.

Relative confidence is computed as the top candidate's final score divided by the sum of all candidate scores for that target word. It reflects how clearly the winner outperformed runner-up candidate senses without claiming to be a calibrated probabilistic distribution.
